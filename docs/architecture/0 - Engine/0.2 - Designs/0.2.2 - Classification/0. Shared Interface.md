Pass 1 emits **one `ClassifierLabel` per source**, containing all of the fields below. Each field is consumed by a specific downstream pass — boundary set drives Pass 3 eligibility, cluster seeds drive Pass 2, importance score drives ordering + L1 manifest priority, sensitivity flags drive retrieval scoping, and so on. Sources that fail mechanical filters in Pass 0 never reach Pass 1; sources that do reach it always get a full label written, even if most fields are nulled out (e.g. autogen content gets `skip_synthesis: true` and short-circuits the rest).

```yaml
ClassifierLabel:
  source_id: <ref>
  content_kind: <enum>            # CODE_KOTLIN | DOC_ADR | SLACK_THREAD | ...
  is_boundary: <bool>
  kind_candidate: <PageKind?>     # decision | flow | feature | sop | insight | framework | null
  domain_candidates: [<string>]   # cluster seeds for Pass 2
  importance_score: <float>       # 0..1
  contextual_confidence: <float?> # override of connector's default confidence
  standards_detected: [<ref>]
  patterns_detected: [<ref>]      # single-source only; cross-source is Pass 2
  skip_synthesis: <bool>          # Haiku judgment beyond mechanical filter
  quality_flags: [<enum>]         # STALE | WIP | INCOMPLETE | CONTRADICTORY
  sensitivity_flags: [<enum>]     # PII | CUSTOMER_DATA | SECRETS_LEAKED
  soft_links: [<candidate edge>]  # Pass 4 input
  classifier_version: <string>
  prompt_version: <string>
  confidence_in_label: <float>    # classifier's own confidence in itself
```
