### Overview
The provenance graph is a directed graph produced from the contents of the source artifact that captures
- every relevant entity, source and region (node)
- all internal structural references (directed edges)

```
  nodes:
    - (source_id) or (source_id, region_id)
  edges:
    - from: (source_id_A, region_id_A)
      to:   (source_id_B, region_id_B)
      edge_kind: calls | imports | extends | cites | mentions
                | quotes | supersedes | blocks | references
      extracted_by: tree-sitter | markdown-parser | slack-api | linear-api | ...
```

The provenance graph is key for outlining all page wikilinks and relationships that need to be conveyed and aggregated during the ingestion of the source material to build the interconnecting patterns

#### Examples
- Code files/Repo
	- **Tools**
		- JGit
		- Tree-Sitter AST Walk
```


module -> class ->  -> imported files -> class functions -> invoked functions 
		    |
		extended class

```

- Markdown Document
	- **Tools**
		- Markdown Parser
		- Frontmatter Read
```

page -> heading -> referenced page
 |
frontmatter/tags -> superseded doc

```
