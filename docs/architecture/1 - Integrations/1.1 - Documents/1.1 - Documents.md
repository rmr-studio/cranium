This is a system that would allow a user, or an entire engineering team to sync their knowledge and document bases, extracting every source of key knowledge
- System architecture
- Feature Design documents
- Source of truth documents
- ADRs
- Project management
- Team onboarding
- Tribal knowledge
- Related research and important information that should be persisted and used as context

This will continuously build the source documents for the internal wiki, being able to link implementations to its original design, or to enforce system design or team standards with what is recorded
- The knowledge base would need to be continuously scanned to identify newly changed files, and if the changes in document have lead to new system requirements and standards that need to be enforced in the future.
